# 个人作品集

记录和分享不同风格的绘画、角色二创与视觉实验。这里会持续收录新的作品，探索色彩、形状、构图与情绪的不同表达。

## 关于创作

本仓库收录个人构思、选择与迭代指导下完成的作品，部分创作使用 AI 辅助。随着作品积累，会逐步加入更多主题与表现手法。
